Enter the Abacus ingress API key to look up spend receipts.
Requests use the X-API-Key header — the same credential the enforced /v1/proxy and /v1/receipts endpoints require. No bypass.

Abacus is a spend-enforcement reverse proxy. Its only authenticated read endpoint is GET /v1/receipts/:request_id — the money system-of-record for a single enforced request. There is no HTTP endpoint that lists receipts, spend policies, budgets, or holds, so this console looks up one receipt by its request_id (the x-request-id correlation key returned by a proxied call). Nothing here is fabricated.
Enter a request_id to view its receipt.
